
# Backend Week 1 Assignment

## Danish Learning API

This project includes three Danish vocabulary routes:

- GET /words - Returns all Danish words.
- GET /words/:id - Returns a Danish word by ID.
- GET /category/:name - Returns words by category.

The homepage displays the total number of users from the SQLite database.
