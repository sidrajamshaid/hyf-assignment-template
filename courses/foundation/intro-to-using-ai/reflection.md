## Question 3

### **How would you explain the difference between using Copilot to generate code for you vs. using it as an effective learning partner?**

> I would use Copilot as an effective learning partner instead of just using it to generate code for me. If it generates everything for me, it can become difficult to understand the code and review all the changes, and I can lose control over what I actually know. When I use it as a learning partner, I can ask it to explain the code, review the changes myself, and learn while I am building.

## Question 4

### **Identify 3 risks of relying too much on AI tools when learning at HackYourFuture.**

 If I rely too much on AI, I may lose my ability to code and solve problems by myself. I may also lose the patience and focus to work on difficult problems for a longer time because I become used to getting quick answers from AI. Another risk is that AI can make mistakes, and if I have not developed my own skills, I may not be able to recognize or correct those mistakes. This could make me more frustrated and even more dependent on AI.
